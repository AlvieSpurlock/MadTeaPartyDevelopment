Short description

Google AdMob for Unity is a Unity plugin for working with Google AdMob in your game.

Long description

Google AdMob for Unity gives Unity developers premade, already-integrated ad Game Objects, including a modular Rewarded Ad Button, plus Banner, Interstitial and Rewarded ads, so Google AdMob can go into a game without wiring every piece by hand. It's part of Mad Tea Party Development's Game Dev Kits, a set of Unity plugins built for the studio's own games first.

Key features

  • Premade, already-integrated ad Game Objects you drop into a scene
  • A premade, modular Rewarded Ad Button
  • Banner, Interstitial and Rewarded ads, ready to use
