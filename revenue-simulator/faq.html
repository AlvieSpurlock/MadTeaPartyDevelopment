▮▮▮ FAQ

Questions before you buy

Straight answers, including what it can't do.

Does it need the internet?

No. The charts library is bundled and the app's own code makes no network requests.

Why does Windows warn me when I open it?

The app isn't code-signed, so Windows SmartScreen shows a warning on first launch. Choose More info, then Run anyway.

How accurate is it?

The math is exact and you can check it by hand. Forecasts depend on your assumptions and have not been validated against live games. See Accuracy and limits.

Can I save my scenarios?

Not in version 1.0, and there's no export yet; closing the app clears your inputs. You can set your own starting values in config.js so new games open with your base case.

Does it include real CPI and ARPDAU data?

No. The market CPIs and the default ARPDAU are rough estimates meant to be replaced with your own numbers.

Does it handle in-app purchases?

No. The model has one ad-revenue-per-user value per game and no purchase revenue, so it suits ad-monetized games.

Can I use it for apps that aren't games?

The model is generic: any app with installs, retention and ad revenue per user fits. The wording and presets are written for mobile games.

Mac or Linux?

Not in this release. It's Windows only.

Can I edit it?

Yes. You get the editable files and the full source project. See Customize and extend.

Can I resell or share my edited copy?

See the license. The terms will be posted before launch.
