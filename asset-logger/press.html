Short description

Asset Logger documents every third-party asset in your game and exports a clean, submission-ready CSV for Steam and other platforms.

Long description

Asset Logger is a small Windows tool that takes the spreadsheet headache out of asset documentation. For each third-party asset it asks six questions (platform, where it's used, how it's used, asset name, creator and license type), shows a formatted summary to confirm, and lets you log as many assets as you need in one session. Everything lands in one tidy CSV, with a safety check before any overwrite, ready to drop into a store submission. March Hare Games used it to document every third-party asset in Scorchlet.

Key features

  • Guided entry: prompts for every required field, so nothing gets missed
  • A confirmation step with a formatted summary before each asset is saved
  • Log as many assets as you need in one session
  • Clean CSV export, ready for a submission package
  • File safety: a check before any overwrite
